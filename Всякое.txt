Этот класс представляет конфигурацию входного сигнала (датчика). В любой момент времени датчик может находиться только в одном режиме, и детали этого режима фиксируются этим классом.
11 байт
1 - порт
2 - Интервал удержания
3 - mode (режим ввода)
4 - NotificationsEnabled ДА, если новые значения отправляются всякий раз, когда значение входных данных выходит за пределы дельта-интервала. Значение True, если включены уведомления
5 - Количество байт. Ожидаемое количество байт в полезной нагрузке входных данных (устанавливается устройством). 
6 - Revision. Редакция <see cref="InputFormat"/> (устанавливается с помощью <see cref="iDevice"/>). Когда для службы устанавливается новый <см. cref="InputFormat"/>, устройство отправляет обновленный <см. cref="InputFormat"/> через	<см. 					       cref="IServiceDelegate".DidUpdateInputFormat"/>. Устройство присвоит номер редакции новому <см. cref="InputFormat"/>. Номер редакции сопоставляется с форматом редакции при получении значений для соответствующей службы.
7 - Идентификатор типа соответствующей службы.
8 - Единица измерения, в которой передаются значения (в виде необработанных значений или в виде значений системы СИ)

			var deltaInterval = BitConverter.GetBytes(inputFormat.DeltaInterval);

public class ConnectInfo
		
1	ConnectId Идентификатор, используемый для уникальной идентификации службы и обращения к ней. Гарантируется, что устройство не будет одновременно использовать две службы с одинаковым идентификатором подключения

2	Revision FirmwareVersion Версия встроенного ПО подключенного устройства ввода-вывода, полученная от устройства

3	Revision HardwareVersion Аппаратная версия подключенного ввода-вывода, полученная от устройства

4	HubIndex Индекс порта на концентраторе, к которому подключен ввод-вывод. Если индекс больше или равен 50, служба является внутренней.

5	Type  Тип ввода-вывода. Это исходный номер типа, полученный от устройства

6	IoType TypeEnum  Тип ввода-вывода. Используйте свойство type, чтобы получить исходный номер типа, полученный от устройства

7	TypeString Тип ввода-вывода в виде строки - полезен для печати в инструкциях отладки

				case IoType.IoTypeTiltSensor:
					return "Tilt sensor";
				case IoType.IoTypeMotionSensor:
					return "Motion sensor";
				case IoType.IoTypeGeneric:
					return "Generic";

					return "Generic";
			}
		}
		
		internal static ConnectInfo FromByteArray(byte[] data) {
			if (data.Length < 2)
				return null;
			if ((data[1] == 1 && data.Length != 12) || (data[1] == 0 && data.Length != 2))
				return null;
			var connectInfo = new ConnectInfo {ConnectId = data[0]};
			if (data[1] == 1) {
				connectInfo.HubIndex = data[2];
				var typeId = data[3];
				connectInfo.Type = typeId;
				if (typeId == 1)
					connectInfo.TypeEnum = IoType.IoTypeMotor;
				else if (typeId == 20)
					connectInfo.TypeEnum = IoType.IoTypeVoltage;
				else if (typeId == 21)
					connectInfo.TypeEnum = IoType.IoTypeCurrent;
				else if (typeId == 22)
					connectInfo.TypeEnum = IoType.IoTypePiezoTone;
				else if (typeId == 23)
					connectInfo.TypeEnum = IoType.IoTypeRgbLight;
				else if (typeId == 34)
					connectInfo.TypeEnum = IoType.IoTypeTiltSensor;
				else if (typeId == 35)
					connectInfo.TypeEnum = IoType.IoTypeMotionSensor;
				else
					connectInfo.TypeEnum = IoType.IoTypeGeneric;

				connectInfo.HardwareVersion = Revision.FromByteArray(data.ToList().GetRange(4, 4).ToArray());
				connectInfo.FirmwareVersion = Revision.FromByteArray(data.ToList().GetRange(8, 4).ToArray());

			}
			return connectInfo;
