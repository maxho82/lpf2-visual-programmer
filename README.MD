 LPF2 Visual Programmer
Визуальная среда программирования для LPF2/WeDo 2.0 хабов на языке Go с графическим интерфейсом.

🚀 Обзор проекта
LPF2 Visual Programmer — это приложение для визуального программирования роботов и устройств на базе LPF2-совместимых хабов (WeDo 2.0, Powered Up, Boost и других). Программа позволяет создавать программы с помощью блоков, соединять их визуально и выполнять на физическом устройстве через Bluetooth LE.

Основные возможности:
🔍 Автоматический поиск и подключение к LPF2 хабам

🧩 Визуальное программирование с помощью блоков

🎮 Управление моторами, светодиодами, датчиками

💾 Сохранение и загрузка программ

🎨 Современный графический интерфейс с темной темой

🖥️ Кроссплатформенность (Linux, Windows, macOS)

🛠 Технический стек
Язык: Go 1.24.9

GUI: Fyne v2.7.1

BLE: tinygo Bluetooth v0.13.0

Протокол: LPF2 (LEGO Powered Up/WeDo 2.0)

Архитектура: Модульная, с разделением логики и интерфейса

Типы блоков:
BlockTypeStart - Начало программы

BlockTypeMotor - Управление мотором

BlockTypeLED - Управление RGB светодиодом

BlockTypeWait - Пауза в программе

BlockTypeLoop - Цикл повторений

BlockTypeStop - Остановка программы

⚙️ Установка и запуск
Предварительные требования:
Go 1.24.9 или выше

Bluetooth адаптер с поддержкой BLE

LPF2-совместимый хаб (WeDo 2.0, Powered Up и т.д.)

Установка зависимостей:
bash
# Клонирование репозитория
git clone <repository-url>
cd lpf2-visual-programmer

# Установка зависимостей
go mod download
Сборка и запуск:
bash
# Сборка приложения
go build -o lpf2-programmer .

# Запуск (для Linux может потребоваться sudo для доступа к Bluetooth)
./lpf2-programmer
Запуск в режиме разработки:
bash
go run main.go
🎮 Использование
Подключение к хабу:
Включите хаб (должен начать мигать светодиод)

Нажмите кнопку "Поиск хаба" в приложении

Выберите найденный хаб из списка

Нажмите "Подключиться"

Создание программы:
Перетащите блоки из панели слева на холст

Настройте параметры блоков в правой панели

Соедините блоки последовательно

Нажмите "Запуск" для выполнения программы

Доступные блоки:
Начать - стартовая точка программы

Мотор - управление мощностью и направлением мотора

Светодиод - установка цвета RGB светодиода

Ждать - пауза на указанное время

Повторять - цикл заданное количество раз

Стоп - остановка выполнения программы

🔧 Особенности реализации
Bluetooth LE на Linux:
Приложение использует tinygo.org/x/bluetooth для работы с BLE. Для Linux систем могут потребоваться дополнительные разрешения:

bash
# Даем разрешения на использование Bluetooth
sudo setcap 'cap_net_raw,cap_net_admin+eip' lpf2-programmer
Протокол LPF2:
Приложение поддерживает протокол LPF2, используемый в:

LEGO WeDo 2.0

LEGO Powered Up

LEGO Boost

LEGO Mindstorms

🐛 Известные проблемы и ограничения
Текущие ограничения:
Поддержка только Linux - приложение тестировалось на AltLinux, но должно работать на других дистрибутивах

Ограниченный набор блоков - в текущей версии реализованы основные блоки

Базовая обработка ошибок - требуется улучшение обработки сетевых ошибок

Проблемы с подключением:
Если возникают проблемы с подключением к хабу:

Проверьте, что хаб в режиме подключения (мигает)

Убедитесь, что Bluetooth адаптер включен

Попробуйте перезагрузить хаб

Запустите приложение с правами root (если необходимо)
